# Proportional English font for PAW.EXE's text engine, drawn for this project (MIT, same as the repo).
# A block is "=C" (the character; "=SP" is a space, "=ELL" the ellipsis, code 0x7F) then up to 10 rows, '#' on, '.' off.
# Rows are cell rows 1-10: capitals use 1-8, x-height starts at row 3, descenders use 9-10.
# Width = row length. The game adds a 1 px outline, so the build puts a glyph at column 1 of its 12x11 cell; 10 px is the maximum.
